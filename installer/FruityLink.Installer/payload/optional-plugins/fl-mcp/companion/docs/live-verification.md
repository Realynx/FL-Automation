# Live FL verification

Live verification completed September 12, 2026 on FL Studio 26.1.3.5570 covers disposable launch, project identity, Python 3.14.6 in the same FL process, authoring, snapshot save/reload, and command-line WAV rendering. Saved and untitled assistive attachment also passed: same-process Python read/edit/restore, snapshot identity/song-mode preservation, close/render refusal, exclusive lease, handover, and companion exit preserving FL. Automated tests alone do not establish support for another executable or native layout.

The installed 0.1.10 framework distribution with FLMCP 0.2.0 rendered the four-bar **Neon Steps** demo at 128 BPM / 96 PPQ. A managed copy of its saved project reloaded 56 drum notes, 16 bass notes, and two playlist clips, each 1536 ticks long. `fl_project_render` saved a verified snapshot, closed its disposable editor, completed the real FL renderer with exit code zero, and returned a validated WAV. The original project was preserved separately.

The WAV measured 7.5 seconds, stereo, 48 kHz, 32-bit floating point, and 2,880,184 bytes. Peak was -12.284 dBFS and RMS -28.176 dBFS, with no clipped or non-finite samples. Audio was measured, not auditioned. Local evidence: `artifacts/neon-render-20260912-175638.json` and the companion `Neon Steps - rendered 20260912-175638.verification.json` beside the WAV. These local reports are not required distribution files.

The installed **0.1.12** framework repeated the full render after removing a version-dependent raw song-length write. Ghidra analysis showed that FL 2026 uses the old `+0xB04` location as part of a viewport double; refreshing the current arrangement now lets FL update its own cached length. The textual length comes from valid playlist clip spans, including unselected clips. In a disposable copy, adding, resizing, and deleting a clip changed reported length through **4 → 8 → 6 → 4 bars**, and FL's actual playback-range ends followed **1535 → 3071 → 2303 → 1535 ticks**. The restored composition rendered successfully with the same duration and audio measurements above. The editor reopened with 72 notes, two four-bar clips, and the corrected four-bar readout, stopped at tick zero.

Final local evidence: `artifacts/neon-render-20260912-180733.json` and `Neon Steps - rendered 20260912-180733.verification.json` beside its WAV. The SDK's 126 FL bridge tests passed, including 20 song-state regression cases; the native installer passed 33 published-package checks. An intermediate 0.1.11 pointer-only correction failed the live length assertion and was superseded by 0.1.12.

This validates one sampler-based composition and the render path on the stated build. Listening, other generators/effects, alternate render settings, live render failure/cancellation recovery, and the remaining scenarios below still require verification. Reported song length assumes 4/4 and describes clip content; marker-only tails and active selections may change the actual export range.
